# ローカルAIモデル選定とライセンス

現行機能は、Transformers.js + ONNX Runtime WebによるCPU/WASM実行です。

## 現行モデル

### 日本語NER

- ID: `jiting/xlm-roberta-ner-japanese_onnx`
- revision: `8d70fc4d277a84e59ccc70520ffd9daff66e66f0`
- dtype: `q8`
- 用途: 人名、組織名、場所、施設、製品、イベントなどの実体候補
- 変換元: `tsmatz/xlm-roberta-ner-japanese`
- 表示されているライセンス: MIT License

NERは生成モデルではありません。入力文に存在するトークンの候補を返し、検出範囲が確認できた場合だけ候補として表示します。住所全体や固有名詞を常に正しく抽出できることは保証しません。

### Ruri-v3-30m

- ID: `sirasagi62/ruri-v3-30m-ONNX`
- revision: `cdf9391f1ff2198daa8f63f7ccf97d7b3e7415a0`
- dtype: `q8`
- 用途: 契約、人事、法務、財務、社内、未公開、機密文脈などの候補
- 元モデル: `cl-nagoya/ruri-v3-30m`
- 利用条件: Apache License 2.0

Ruriは日本語の埋め込みモデルです。文章生成やプロンプト実行ではなく、短い文脈と固定したリスク説明との類似度を使った補助分類に利用します。

## 実行方式

- Transformers.jsでモデルを読み込む。
- ONNX Runtime WebのWASMバックエンドを使用する。
- CPUスレッド数を制限し、UIスレッドを直接ブロックしないWorkerで実行する。
- モデルファイルは初回利用時に第三者配信元から取得する場合がある。
- 取得後はブラウザのキャッシュや管理下の保存領域を利用する。
- ユーザー本文はモデル配信元や外部LLM APIへ送信しない。
- NERまたはRuriの片方が失敗しても、もう片方とルールベース検出を継続する。
- 両方が失敗しても、ルールベース検出は維持する。

## 選定理由

WebGPUの可否やGPUドライバに依存せず、内蔵GPUやWebGPUが使えない環境でも同じ経路を試せることを優先しました。Ruriは日本語文脈分類に適した小型モデル、NERモデルはエンティティ候補の抽出に役割を限定しています。

モデルファイルは合計で大きくなる場合があります。初回ロード時間、保存容量、CPU性能、モデル配信元への接続状況によって利用できない場合があるため、AI候補を安全判定の必須条件にはしません。

## やらないこと

- 外部LLM APIへの本文送信
- 文章生成、依頼文生成、要約
- WebLLM、WebGPUへの依存
- AI候補だけによる送信許可・送信ブロックの最終決定
- モデルファイルや本文の永続保存

詳細な第三者ライセンスは [NOTICE](../NOTICE) を参照してください。
