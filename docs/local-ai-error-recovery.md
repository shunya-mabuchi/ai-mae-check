# ローカルAIエラー分類と復旧

現行のAI経路ではWebGPUや生成モデルを使いません。

対象モデルは `jiting/xlm-roberta-ner-japanese_onnx` q8 と `sirasagi62/ruri-v3-30m-ONNX` q8 です。
実行にはTransformers.jsとONNX Runtime Webを使用します。

| kind | 主な原因 | ユーザー向け案内 |
| --- | --- | --- |
| `model_fetch` | モデル配信元への接続失敗 | 接続、プロキシ、セキュリティソフト、モデル配信元を確認する |
| `storage` | キャッシュ保存領域不足、シークレットモードの制限 | サイトデータと空き容量を確認し、通常ウィンドウで再試行する |
| `memory` | CPUメモリ不足 | 他のタブやアプリを閉じて再試行する |
| `worker` | AI Workerの起動・通信失敗 | 対象タブを再読み込みして再試行する |
| `wasm` | WebAssemblyまたはONNX Runtimeの初期化失敗 | 拡張機能と対象タブを再読み込みする |
| `timeout` | 初期化または推論の時間超過 | 入力を短くして再試行する |
| `unknown` | 上記以外 | 本文を含めず、OS、Chrome、分類、技術詳細を報告する |

## 共通のフォールバック

AI文脈チェックの失敗は、ルールベース検出の失敗を意味しません。UIは「ルールベースの検出結果は引き続き利用できます」と表示し、確定情報の検出と安全化を継続します。NERまたはRuriの片方だけが失敗した場合も、もう片方の候補を表示します。

## 取得失敗

モデルファイルは初回利用時に第三者配信元から取得される場合があります。本文は送信されません。接続制限やモデル配信元の状態で取得できない場合、再試行を促し、本文を含まない診断だけを表示します。

## 保存容量・メモリ不足

モデルファイルは合計で大きくなる場合があります。ブラウザの保存容量や端末メモリが不足するとAIを利用できません。その場合もルールベース検出は利用できます。診断ログへ入力本文や検出文字列を含めません。

## 実機確認

WebGPU、Dawn Info、D3D11/D3D12を必須条件にしません。CPU/WASM経路の成功、部分成功、失敗を [ローカルAI互換性マトリクス](local-ai-compatibility-matrix.md) に本文なしで記録します。
