# サポートFAQ

## AI文脈チェックを使う前に確認すること

- 初回はモデルファイル取得のため時間がかかる場合があります。
- 通常ウィンドウで、十分な保存容量とメモリがある状態で試します。
- モデル配信元への接続がプロキシやセキュリティソフトで制限されていないか確認します。
- AIが使えなくても、ルールベース検出と安全化は利用できます。

## AI文脈チェックが動かないのはなぜですか？

現行のAI経路はTransformers.js + ONNX Runtime WebのCPU/WASMです。主な原因は、モデル配信元への接続失敗、ブラウザ保存領域不足、端末メモリ不足、WorkerやWebAssemblyの初期化失敗、入力が長すぎることです。NERまたはRuriの片方だけが失敗する場合は、利用できた候補とルールベース結果を表示します。両方が失敗してもルールベース検出は継続します。

## モデル取得時に本文は送信されますか？

送信されません。モデルファイルは第三者配信元から取得される場合がありますが、ユーザー本文は外部LLM API、開発者サーバー、ルール配信サーバーへ送信しません。

## AIは安全と断言しますか？

しません。AIは人名・組織名・場所・施設などの実体候補と、契約・人事・法務・財務・社内・未公開などの文脈候補を提示する補助機能です。確定情報の検出と送信ポリシーはルールベースを主役にします。

## どの情報を記録して報告すればよいですか？

拡張バージョン、Chrome/OS概要、エラー分類、モデルID、本文を含まない技術詳細を記録してください。貼り付け本文、送信本文、検出文字列、placeholderMap、Cookie、トークン、現在のページURLは含めないでください。
