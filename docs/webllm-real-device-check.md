# ローカルAI実機確認メモ

このファイル名は過去のWebLLM検証記録との互換性のために残しています。現行のAI文脈チェックは、Transformers.js + ONNX Runtime WebのCPU/WASM経路です。

使用モデルは `jiting/xlm-roberta-ner-japanese_onnx` q8 と `sirasagi62/ruri-v3-30m-ONNX` q8 です。

## 成功時

1. 通常ウィンドウで対象サイトを開く。
2. AI文脈チェックを実行する。
3. NER候補とRuri文脈候補が表示されることを確認する。
4. 候補は自動で確定扱いされず、チェックボックスで安全化対象を選べることを確認する。
5. ルールベースの高リスク検出とマスキングが維持されることを確認する。

## 部分成功時

NERまたはRuriの片方だけが利用できない場合、UIは部分成功の警告を表示し、利用できた候補とルールベース結果を表示します。本文や失敗したモデルの詳細を診断画面へ出しません。

## 失敗時

モデル取得、保存容量、メモリ、Worker、WASM、タイムアウトを確認します。AIが完了できなくても、ルールベース検出は利用できる必要があります。シークレットモードでは保存容量が制限される場合があるため、初回モデル取得は通常ウィンドウで行います。

## 記録してよい情報

- OS、Chrome、CPU、メモリ
- モデルID、revision、dtype
- エラー分類と本文を含まない技術詳細
- ルールベース検出が継続したか

記録してはいけない情報は、貼り付け本文、検出文字列、placeholderMap、Cookie、トークン、アカウント識別子です。

エラー分類は `model_fetch`、`storage`、`memory`、`worker`、`wasm`、`timeout`、`unknown` から選びます。
