# AIまえチェック v0.1.2 リリースノート案

## 概要

公開基盤をGitHub Pagesへ統一し、署名付き追加ルールをビルド時に生成する構成へ移行します。

## 主な変更

- LP、プライバシー方針、サポートページをGitHub Pagesへ移行
- 署名付きルール配信先を `/api/rules/latest.json` へ変更
- GitHub ActionsとEnvironment Secretによるビルド時署名を導入
- Cloudflare Worker / Pages Functionsの実行時依存を削除
- GitHub Pages向けの直接URL、SEO、公開QAを追加

## 注意

情報漏洩を完全に防ぐものではありません。検出漏れや誤検出が起きる可能性があるため、送信前にユーザー自身で内容を確認してください。
